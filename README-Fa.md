# اسکریپت Gost IP6 — نسخهٔ بهینه‌شده

[English](README.md) | [فارسی](README-Fa.md)

نصب‌کننده و مدیریت‌کنندهٔ تعاملی تونل **Gost** (IPv4 / IPv6) همراه با بهینه‌سازی
خودکار سرور و دانلود پرسرعت (jsDelivr CDN).

</div>

---

## نصب

روی سرور و با دسترسی **root** اجرا کنید:

```bash
bash <(curl -Ls https://cdn.jsdelivr.net/gh/Aknuun/Gost-ip6@v2.3.1/install.sh)
```

اسکریپت خودش را در `/etc/gost/install.sh` نصب می‌کند، بنابراین بعد از آن فقط با تایپ:

```bash
gost
```

منو دوباره باز می‌شود.

> پیش‌نیاز: دسترسی root، `bash` و سیستم مشابه Debian/Ubuntu (تست‌شده روی Ubuntu 20.04 / 22.04 / 24.04 / 26.04).

## این نسخه چه چیزهایی اضافه کرده

این یک فورک از [masoudgb/Gost-ip6](https://github.com/masoudgb/Gost-ip6) (نسخهٔ 2.2.0) است
که برای پایداری در محیط واقعی بهینه شده:

### ۱) سواپ خودکار
قبل از نصب، یک فایل سواپ متناسب با RAM و فضای دیسک سرور ساخته می‌شود
(مثلاً حدود ۲GB سواپ روی سروری با ۲GB رم). این کار جلوی کشته‌شدن تونل توسط
OOM-killer کرنل را می‌گیرد. مقدار `vm.swappiness` روی `10` تنظیم می‌شود
(به‌عنوان پشتیبان، نه سواپ فعال).

### ۲) تیونینگ کرنل و شبکه
در فایل `/etc/sysctl.d/99-gost-tuning.conf` نوشته و به‌صورت دائمی اعمال می‌شود:
- `nf_conntrack_max = 262144`
- `somaxconn`، `tcp_max_syn_backlog`، `netdev_max_backlog`
- `tcp_tw_reuse`، `tcp_fin_timeout`، `tcp_slow_start_after_idle`
- بافرهای بزرگ‌تر `rmem`/`wmem`، `fs.file-max` بالاتر و `swappiness=10`

### ۳) محدودکردن حجم journal
مقدار `SystemMaxUse=200M` تا لاگ‌های هر اتصالِ gost دیسک را پر نکنند
(پیکربندی قبلی می‌توانست ژورنال را از ۱GB هم بگذراند).

### ۴) یونیت‌های سیستمی سخت‌شده
هر `gost_*.service` با این تنظیمات ساخته می‌شود:
```
Restart=always
RestartSec=5
StartLimitIntervalSec=0
OOMScoreAdjust=-1000
LimitNOFILE=1048576
TasksMax=infinity
After=network-online.target
```
پس اگر gost کرش کند یا OOM-kill شود، خودکار برمی‌گردد و از انتخاب‌شدن توسط
OOM-killer محافظت می‌شود.

### ۵) دانلود پرسرعت (jsDelivr CDN)
باینری‌های Gost و خود اسکریپت از CDN جی‌اس‌دلیور دانلود می‌شوند (به‌جای گیت‌هاب)
که روی سرور ایران خیلی سریع‌تر و پایدارتر است. با `wget` ساده و fallback به
`curl` — بدون هیچ دست‌کاری در DNS سرور.

### ۶) بدون پرسیدن نسخه
نصب تونل همیشه از **Gost رسمی 2.11.5** استفاده می‌کند و دیگر نمی‌پرسد
«رسمی یا آخرین نسخه».

## گزینه‌های منو

| # | گزینه |
|---|-------|
| ۱ | تونل Gost با IP4 |

## نکات پیکربندی

- پروتکل‌ها: `tcp`، `udp`، `grpc`.
- محدودهٔ پورت باید بین `54` و `65000` باشد؛ از پورت‌های تکراری استفاده نکنید.
- هر زمان خواستید منو را با دستور `gost` دوباره باز کنید.
